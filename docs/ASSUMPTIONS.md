# Assumptions

Calls made without asking, because the answer was reasonable and waiting would have
cost more than being wrong. Each is one line: question → decision → reason. Overrule
any of them and the code follows.

- [2026-09-29] How does the first teacher account come to exist on a fresh install? → Admin adds a teacher by phone + name (`POST /api/admin/teachers`); if the phone already belongs to a student, the admin is offered a promotion (`PATCH /api/admin/users/{id}/role`) → the admin mockup has an "O'qituvchi qo'shish" button, login is passwordless (phone + Telegram OTP), and without it prod has no teachers at all.
- [2026-09-29] Who publishes the official (`public`) catalog? → Admins only, from an admin "Kontent" section that reuses the teacher content editor; teachers still cannot self-grant `public` → a fresh install otherwise shows teacherless students an empty catalog, and the admin mockup lists Kontent in its nav.
- [2026-09-29] Does publishing a module publish its tasks? → Yes: false→true on the module publishes every draft task in it, and a task created inside a module inherits the module's state; the per-task toggle stays → the editor has no task-level publish control, so every teacher-authored task stayed a draft forever and never reached a student.
- [2026-09-29] Which answers may a teacher see? → Answers by students in the teacher's groups, to any question including the official catalog — roster only, NOT also "answers to my own questions" (that would expose students outside the teacher's groups, and let the author of a public module see every learner on the platform) → a class practising the official catalog otherwise gives its teacher an empty queue, gradebook and analytics.
- [2026-09-29] Can a teacher grant Premium? → Yes, for students in the teacher's own groups; admins for anyone → the legacy product allowed it, the student-facing copy already promises it, and teacher-granted premium is the documented regression to protect.
- [2026-09-29] Deleting a task or module → soft delete that never removes student answers or grades → every FK into users/questions cascades, and a student's history is not the teacher's to destroy.
- [2026-09-30] Can a teacher assign tasks from the official catalog, and can a free student then open them? → Yes to both: a teacher may assign any live official task or module; a LIVE assignment (deadline not passed) unlocks that one task for that student past the free preview and the sequence lock, and `max_attempts` bounds the retries → the official catalog is the main content, homework a student cannot open is useless, and a teacher can already grant premium outright, so it opens no new bypass.
- [2026-09-30] When does "a day" end for streaks, daily limits and weekly trends? → Local midnight in Tashkent (UTC+05:00), one rule in `Govori.Contracts/ProductDay` → the product serves Uzbekistan only (no DST), no timezone is stored per user, and the streak is written by the worker with no request to read one from; UTC midnight was 05:00 local.
- [2026-10-21] Is the module order enforced or only shown? → Enforced at submit: a student's answer to a task whose predecessor they have not answered is a 403, checked after the 402; a live assignment and the review queue open it, and any non-failed answer to the predecessor counts (not only a graded one) → the view already hid the locked task's prompt, so skipping ahead was only possible by a direct POST, and "graded" would race the grading worker.
- [2026-10-21] The anonymous guest demo (`/api/guest/{demo,assess,tts}`) → Removed, module and all; the guest placement test stays → nothing in the SPA called it, and `/assess` spent Azure money for anyone on the internet behind only a per-IP limit.
- [2026-10-21] Which language is graded feedback written in? → The student's `preferred_language` (uz/ru/en; unknown → uz), read when grading runs, recorded as `lang` in the feedback JSON; ru is simple A1–B1 Russian; placement/profile CEFR captions follow the UI language too → a ru/en student was reading Uzbek feedback next to a Russian/English interface; the uz prompt is byte-identical, so the golden set still measures what it did.
- [2026-10-21] What moves when an admin hands a group to another teacher? → Ownership, pending join requests and the assignments the previous teacher set through the group; answers, grades, premium grants, the join code and leaderboards stay; the previous teacher's own modules stay theirs (students keep only tasks they hold a live assignment for); students and both teachers are notified → least surprise for students, no history rewritten, and a teacher's content may serve their other classes.
- [2026-10-21] What does the admin audit trail record? → Every 2xx mutation on an admin route, plus revealing a secret; field NAMES always, values only from a per-route allow-list and never anything named key/secret/token/password; append-only by DB trigger, no FKs → refused requests change nothing, and a log that can leak or lose the secret it audits is worse than none.
