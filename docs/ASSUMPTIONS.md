# Assumptions

Calls made without asking, because the answer was reasonable and waiting would have
cost more than being wrong. Each is one line: question → decision → reason. Overrule
any of them and the code follows.

- [2026-09-29] How does the first teacher account come to exist on a fresh install? → Admin adds a teacher by phone + name (`POST /api/admin/teachers`); if the phone already belongs to a student, the admin is offered a promotion (`PATCH /api/admin/users/{id}/role`) → the admin mockup has an "O'qituvchi qo'shish" button, login is passwordless (phone + Telegram OTP), and without it prod has no teachers at all.
- [2026-09-29] Who publishes the official (`public`) catalog? → Admins only, from an admin "Kontent" section that reuses the teacher content editor; teachers still cannot self-grant `public` → a fresh install otherwise shows teacherless students an empty catalog, and the admin mockup lists Kontent in its nav.
- [2026-09-29] Does publishing a module publish its tasks? → Yes: false→true on the module publishes every draft task in it, and a task created inside a module inherits the module's state; the per-task toggle stays → the editor has no task-level publish control, so every teacher-authored task stayed a draft forever and never reached a student.
- [2026-09-29] Which answers may a teacher see? → Answers by students in the teacher's groups, to any question including the official catalog — roster only, NOT also "answers to my own questions" (that would expose students outside the teacher's groups, and let the author of a public module see every learner on the platform) → a class practising the official catalog otherwise gives its teacher an empty queue, gradebook and analytics.
- [2026-09-29] Can a teacher grant Premium? → Yes, for students in the teacher's own groups; admins for anyone → the legacy product allowed it, the student-facing copy already promises it, and teacher-granted premium is the documented regression to protect.
- [2026-09-29] Deleting a task or module → soft delete that never removes student answers or grades → every FK into users/questions cascades, and a student's history is not the teacher's to destroy.
- [2026-09-30] Can a teacher assign tasks from the official catalog, and can a free student then open them? → Yes to both: a teacher may assign any live official task or module; a LIVE assignment (deadline not passed) unlocks that one task for that student past the free preview and the sequence lock, and `max_attempts` bounds the retries → the official catalog is the main content, homework a student cannot open is useless, and a teacher can already grant premium outright, so it opens no new bypass.
- [2026-09-30] When does "a day" end for streaks, daily limits and weekly trends? → Local midnight in Tashkent (UTC+05:00), one rule in `Govori.Contracts/ProductDay` → the product serves Uzbekistan only (no DST), no timezone is stored per user, and the streak is written by the worker with no request to read one from; UTC midnight was 05:00 local.
- [2026-10-21] Is the module order enforced or only shown? → Enforced at submit: a student's answer to a task whose predecessor they have not answered is a 403, checked after the 402; a live assignment and the review queue open it, and any non-failed answer to the predecessor counts (not only a graded one) → the view already hid the locked task's prompt, so skipping ahead was only possible by a direct POST, and "graded" would race the grading worker.
- [2026-10-21] The anonymous guest demo (`/api/guest/{demo,assess,tts}`) → Removed, module and all; the guest placement test stays → nothing in the SPA called it, and `/assess` spent Azure money for anyone on the internet behind only a per-IP limit.
- [2026-10-21] Which language is graded feedback written in? → The student's `preferred_language` (uz/ru/en; unknown → uz), read when grading runs, recorded as `lang` in the feedback JSON; ru is simple A1–B1 Russian; placement/profile CEFR captions follow the UI language too → a ru/en student was reading Uzbek feedback next to a Russian/English interface; the uz prompt is byte-identical, so the golden set still measures what it did.
- [2026-10-21] What moves when an admin hands a group to another teacher? → Ownership, pending join requests and the assignments the previous teacher set through the group; answers, grades, premium grants, the join code and leaderboards stay; the previous teacher's own modules stay theirs (students keep only tasks they hold a live assignment for); students and both teachers are notified → least surprise for students, no history rewritten, and a teacher's content may serve their other classes.
- [2026-10-21] What does the admin audit trail record? → Every 2xx mutation on an admin route, plus revealing a secret; field NAMES always, values only from a per-route allow-list and never anything named key/secret/token/password; append-only by DB trigger, no FKs → refused requests change nothing, and a log that can leak or lose the secret it audits is worse than none.
- [2026-10-21] Is there a ceiling on total AI spend, not just per user? → Yes: a global daily and monthly cap on ESTIMATED spend (Tashkent `ProductDay` calendar) plus an admin "pause all AI" switch, in Sozlamalar → AI byudjeti (`/api/admin/settings/ai-budget`, audited as `settings.ai_budget.update`); env defaults `AI_DAILY_CAP_USD` / `AI_MONTHLY_CAP_USD` / `AI_PAUSED`, unset → **$10/day, $200/month** (~800 attempts/day at the $0.012 target), malformed → the same defaults with a warning, never "unlimited"; a warning is logged at 80% and at 100% → per-user limits cannot stop a retry storm, a re-enqueue bug or a sign-up wave, and the amounts are placeholders for the owner to set.
- [2026-10-21] How is an AI call's cost estimated? → Per call, in the chain, after the vendor answers (or fails): STT per audio second (exact for WAV, else the vendor's reported duration, else bytes at an assumed 32 kbit/s — over-counting), graders per token the vendor reports (Opus thinking counted as output), or a flat 3,000 in / 1,500 out when none is reported (failed/timed-out calls are charged too — they are usually billed). Unit prices per backend, not per model, env-configurable (`AI_PRICE_*`); defaults are list prices for the default models (Azure STT $1/h, Whisper $0.006/min, Opus 5 $5/$25, gpt-4o-mini $0.15/$0.60 per 1M tokens) and Gemini 3.1 Flash-Lite is set at $0.25/$1.50 because its price was not verified → an estimate that is wrong on the HIGH side closes the cap early, which is the safe direction; pinning a pricier model without updating its price is the one way to under-count.
- [2026-10-21] What does a student see when AI is paused or a cap is reached? → What they already see when no AI key is configured: placement answers its 503 "later", roleplay and the sound drill show their `unconfigured` state (no turn/attempt used). A graded answer is still uploaded and stored, then fails AT ONCE with the new code `ai_unavailable` ("try again later") instead of deferring — a deferred attempt would sit pending until the sweeper fails it 20 minutes later; failed attempts do not count against an assignment's attempt budget. The admin key probe is not gated (checking a key while paused is when you need it) but its spend is recorded → no new UX, nothing the student recorded is thrown away, and the screen answers now rather than after a spinner.
- [2026-10-21] How exact is the cap under concurrency? → Check-then-call, no reservation: every vendor call (fallbacks included) first reads the shared ledger, and the ledger increment is one atomic upsert. Requests that pass the check together each make their one call, so the total can overshoot the cap by at most one in-flight call per concurrent request (cents at the worker's concurrency) — bounded, never unbounded: once the recorded total reaches the cap, no new call starts in any process. The pause switch reaches other processes through the existing settings broadcast (Redis; ≤30 s cache TTL without it); calls already in flight finish → a reservation needs the cost BEFORE the call, and for a grader nobody knows that until the vendor answers.
- [2026-10-21] An answer with no words in it (silence, a muted mic) → Not sent to the grader: it fails at once as `no_speech` ("we heard nothing — check the microphone and record again"), no evaluation row, does not count against an assignment's attempts → the grader used to score it 0 with a lecture about an empty transcript and a "None" strength, billed like any call; the UI audit's "English feedback in an Uzbek UI" was exactly that row (graded while the dev student's UI was English, so `lang: en` was correct).
- [2026-10-21] Placeholder list items ("None", "N/A", "-", "нет", "yoʻq", blank) in strengths/improvements/vocabulary → Dropped when the vendor answer is parsed AND again before the evaluation is stored (`FeedbackText`), and once more by the client parser for rows stored earlier; a list left empty hides its section → in no language does "None" under "Strengths" tell the student anything.
- [2026-10-21] AI feedback whose `lang` differs from the reader's UI language (pre-S9 rows — no `lang`, all Uzbek; a student who switched language after grading; every teacher reading a student's feedback) → Shown as stored, never re-translated, with one muted line under it: "This AI feedback was written in English." (`FeedbackLangNote`) → the stored text is the record of what the student was told, re-translating costs a model call per view, and silently mixed languages looked like a bug.
- [2026-10-26] Production host → Hetzner CAX11 (2 vCPU Ampere arm64, 4 GB, 40 GB, Ubuntu 26.04) at 91.98.88.56; images built on the Mac with `PLATFORM=linux/arm64 deploy/build-images.sh` → the code has no x64-only native dependency, the idle stack uses ~350 MB, and native arm64 builds skip emulation entirely.
- [2026-10-26] govorim.uz behind Cloudflare (proxied, Full strict) → nginx trusts CF-Connecting-IP from Cloudflare's ranges only (`cloudflare-realip.conf`), recordings carry `Cache-Control: private`, and `deploy/cloudflare-firewall.sh` locks 80/443 to Cloudflare in DOCKER-USER → without realip every per-IP rate limit would throttle all students as one Cloudflare edge; ufw alone cannot gate Docker-published ports.
- [2026-10-26] Server secrets → generated fresh on the server (Postgres, MinIO root/app/backup, SECRET_KEY), never the dev values; only the vendor keys (Azure Speech, OpenAI, Gemini, Telegram bot) were copied from the dev `.env` → a dev secret has been on a laptop and in dev containers; the vendor keys are the same accounts either way.
